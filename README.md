# Multi-Modal Chatbot

This project is a **multi-modal chatbot** that can understand both **text** and **images** using Python, BLIP, and GPT-Neo.

---

## Features

- Generate concise captions for images using **BLIP**.
- Generate text responses based on user input or image description using **GPT-Neo**.
- CPU-friendly for low-end machines (like i3 laptops).
- Beginner-friendly structure for easy extension.
